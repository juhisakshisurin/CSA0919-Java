# Java Programming Lab Experiments

## Overview

This repository contains Java programming lab experiments developed as part of the **Java Programming** course. It serves as a collection of practical implementations designed to strengthen programming fundamentals, logical thinking, and problem-solving skills using Java.

## Objectives

- Understand Java programming fundamentals and syntax.
- Develop logical thinking through practical coding exercises.
- Implement programs using classes, objects, methods, and control structures.
- Practice object-oriented programming concepts.
- Improve coding, debugging, and problem-solving skills.

## Technologies Used

- **Programming Language:** Java
- **Development Environment:** Any Java-compatible IDE or text editor
- **Execution:** Java Development Kit (JDK)

## Repository Contents

This repository contains Java source files for lab experiments and programming exercises. The programs cover the concepts and tasks included in the course syllabus.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed.
- A terminal or Java-compatible IDE.
- Basic knowledge of Java programming.

### Clone the Repository

```bash
git clone https://github.com/juhisakshisurin/CSA0919-Java.git
```

Navigate to the repository:

```bash
cd CSA0919-Java
```

## How to Compile and Run

1. Open the required `.java` source file.
2. Compile the program:

   ```bash
   javac FileName.java
   ```

3. Execute the compiled program:

   ```bash
   java FileName
   ```

Replace `FileName` with the actual Java class name, without the `.java` extension.

**Note:** The source filename should match the public class name, and the installed JDK should support the Java features used in the program.

## Learning Outcomes

By completing these experiments, students gain practical experience in Java syntax, program development, debugging, and applying programming concepts to solve computational problems.
